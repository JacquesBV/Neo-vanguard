Neo Vanguard — pack28, refonte du niveau final

Contenu du pack :
- index.html : code du jeu avec le parcours final retravaillé.
- assets/final/ : nouveaux décors spatiaux, intérieurs et sas.
- assets/enemies/ : sprites détaillés pour les ennemis du niveau final.
- assets/vorax/ : torso, bras et jambes séparés pour animer Vorax par couches.
- assets/embedded/ : les 139 fichiers déjà utilisés par le jeu.

Installation sur GitHub :
1. Décompresse Neo-Vanguard-pack28.zip sur ton téléphone ou ordinateur.
2. Dans le dépôt GitHub Neo-vanguard, remplace le fichier index.html à la racine par celui du pack.
3. Ajoute/fusionne le dossier assets du pack à la racine du dépôt. Garde exactement les sous-dossiers assets/final, assets/enemies, assets/vorax et assets/embedded.
4. Valide les changements (Commit changes), puis attends la mise à jour GitHub Pages.
5. Ferme l'ancien onglet du jeu et ouvre l'adresse du site dans un nouvel onglet. Fais un rechargement forcé si le navigateur garde l'ancien cache.

Les chemins des images sont relatifs à index.html. Ne renomme pas les dossiers ni les fichiers PNG.
